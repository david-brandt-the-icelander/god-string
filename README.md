# god-string
A recreation of the god-string that was used in iPulse

## The articles

[The Great String War](articles/the-great-string-war/README.md) is an eleven-part series about GString for
[icelander.net](https://icelander.net/). The working copies and the notes for publishing are in
`articles/the-great-string-war/`; the site holds only the articles themselves.

## The headers

[`src/gstring/`](src/gstring/README.md) holds C++ headers showing what GString might have looked like. They are a
speculative reconstruction, written in 2026 from memory and the articles: the original source is gone, every name
and signature in them is invented apart from the classes the articles name, and they declare an interface without
implementing it.
